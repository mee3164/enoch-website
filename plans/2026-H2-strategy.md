# 2026 하반기 인스타그램 리브랜딩 전략 (9/28 – 12/31)

- 작성: 2026-09-27
- 목표: 2027년 학원비 인상(특히 입시)에 앞서, 계정만 보고도 "이 학원은 가르치는 방식이 다르다"는 인상이 남도록 프리미엄 포지션을 만든다.
- 기준 문서: CLAUDE.md (원칙 · 말투 · 디자인 · 이미지 규칙)

## 1. 핵심 판단

**프리미엄은 분위기가 아니라 증거로 만든다.** 가격을 올려도 납득되는 학원은 세 가지를 보여 준다.

| 증거 | 계정에서 보여 줄 것 | 연결 원칙 |
|---|---|---|
| 방법 | 1:1 진단 → 맞춤 진도 → 점검. 수업이 실제로 어떻게 흘러가는지 | 1 · 2 · 3 |
| 사람 | 강사 20명 이상의 전공·경력·수업 방식 | 2 |
| 과정 | 학생이 어떻게 준비했는지 (결과 숫자보다 과정) | 1 |

그리고 이것을 **흐트러지지 않는 한 가지 톤**(확정본 No.01의 에디토리얼 디자인)으로 반복한다. 톤이 일정한 것 자체가 고급스러움의 신호다.

### 하지 않을 것
- 가격, 할인, 이벤트, "선착순", "마감 임박" — 피드에서 가격 이야기를 하지 않는다 (CLAUDE.md 3번).
- 합격률·합격 인원 같은 숫자 — 사실 확인이 되고 학생 동의가 있을 때만, 그것도 과정과 함께.
- 유행 음원·밈 릴스 — 조회수는 오를 수 있지만 톤이 무너진다.

## 2. ENOCH ISSUE 발행 주기: **격주 1편 (2주에 1편)** 추천

| | 매주 1편 | **격주 1편 (추천)** |
|---|---|---|
| 12월까지 편수 | 14편 | **7편** (No.01–No.07) |
| 표지 사진 | 매주 새 사진 필요 (재사용 금지 규칙) | 2주에 1장 — 촬영 일정과 맞출 수 있음 |
| 제작 품질 | 10장 × 매주 → 사실 확인·검수가 얇아질 위험 | 편마다 충분한 검수 |
| 인상 | "자주 올리는 정보 계정" | "기다려지는 매거진" |
| 다른 콘텐츠 자리 | 주 2–3회 중 절반 이상을 차지 | 사이 주에 강사·수업·학생 편이 들어갈 자리 |

- 매거진은 드물어야 귀하게 보입니다. 격주면 한 편 한 편이 "호(號)"로 인식되고, 사이 주에 **사람(강사)·방법(LESSON)·과정(STUDENT)** 콘텐츠가 들어가 프리미엄의 세 가지 증거를 모두 채울 수 있습니다.
- 발행 요일은 **월요일 고정**. 한 주를 여는 읽을거리로 자리 잡게 합니다. (주기를 카드 문구로 알리지는 않습니다 — CLAUDE.md 3번)

## 3. 주간 운영 틀 (주 2–3회 + 스토리)

| 요일 | 형식 | 내용 |
|---|---|---|
| **월** | 게시물 (카드뉴스) | 홀수 주: ENOCH ISSUE / 짝수 주: 강사 소개 또는 LESSON |
| **목** | 게시물 (카드뉴스) | LESSON · 입시 시즌 · STUDENT · REVIEW · 공간 |
| **토** | 릴스 (15–30초) | 실제 수업·연습실 소리. 흑백 톤 + 하단 반복 띠, 카드뉴스와 같은 결 |
| 매일 1–3개 | 스토리 | 수업 스케치, 게시물 공유, 질문 스티커. 운영시간·상담은 스토리 하이라이트로 상시 |

- 토요일 릴스는 매주가 목표, 촬영분이 부족한 주는 건너뜁니다 (그래도 주 2회 게시물은 유지).
- **피드 3칸 설계**: 인스타 피드는 3개씩 한 줄로 보입니다. 월(사진 표지) – 목(타이포) – 토(릴스 썸네일)가 한 줄이 되도록 해서, 한 줄마다 "사진 · 글 · 움직임"이 한 번씩 보이게 합니다.

### 하이라이트 (기존 5개 유지, 표지만 통일)
ENOCH / LESSON / STUDENT / REVIEW / 오시는길 — 하이라이트 표지 아이콘을 확정본 디자인(아이보리·블랙, 모노 글씨)으로 새로 만들어 프로필 첫인상을 정리합니다.

## 4. 월별 흐름

### 10월 — 기반: "무엇을, 어떻게 가르치는가"
- ENOCH ISSUE No.01–03, 브랜드 선언(원칙 3가지), 보컬 LESSON, 강사 소개 1, 오시는 길, 수강생 기록
- **수시 실기 기간**: 곡 선정 상담 같은 "준비 시작" 콘텐츠는 맞지 않음 → 대신 **실기 당일·컨디션** 같은 지금 시험을 치르는 학생에게 필요한 내용 (학원의 실제 방식 확인 후)
- 세부 일정: `plans/2026-10.md`

### 11월 — 증거: "누가 가르치고, 학생은 어떻게 준비했는가"
- ENOCH ISSUE No.04 음정 · No.05 톤
- 강사 소개 2–3명 (격주 월요일)
- **수능 직후**: "수능이 끝난 다음 날부터 정시 실기까지" — 정시 실기 준비 콘텐츠 (학원의 실제 정시 대비 방식 확인 후)
- 수시 결과가 나오기 시작하는 시기: 학생·보호자 동의가 있는 경우에만 STUDENT 편 (결과보다 준비 과정 중심)
- REVIEW 1편

### 12월 — 전환: "2027년, ENOCH의 입시"
- ENOCH ISSUE No.06 연습 · No.07 무대 (연말 공연·녹음과 연결)
- **2027 입시반 소개** (12월 중순): 가격 대신 구조를 공개 — 1:1 진단, 주당 수업 구성, 모의 실기·녹음 점검 등 *실제로 운영하는 것만*. 상담은 "예약 상담"으로 안내
- 취미/입시 캠퍼스 분리가 확정되면 예고 (일정 확정 후에만)
- 연말 결산: 한 해의 공연·녹음 기록 (동의 받은 것만)

### 2027년 1월 (다음 단계)
- 새 학원비는 피드가 아니라 **상담에서** 안내하는 것을 권합니다. 피드는 12월까지 쌓은 "방법·사람·과정"의 증거가 대신 설명합니다.

## 5. 사진·영상 확보: 월 1회 "촬영 데이"

하반기 전략의 가장 큰 병목은 사진입니다 (ENOCH ISSUE 표지 재사용 금지, 강사·공간·학생 실사진 필요). 편마다 사진을 요청하는 대신 **한 달에 한 번 반나절 촬영**을 권합니다.

| 촬영 데이 | 찍을 것 |
|---|---|
| 10월 첫째 주 | 강사 상반신 (가능한 인원 전부, 단색 배경·같은 조명), 보컬·기타 레슨 손·악기 클로즈업(No.03·No.04 표지 후보), 레슨실·연습실 전경, 오시는 길 경로 |
| 11월 초 | 드럼·베이스·피아노·미디 작업 장면(No.05 톤 표지 후보), 연습하는 뒷모습, 릴스용 10–20초 클립 여러 개 |
| 12월 초 | 연말 공연·녹음 현장(동의 필수), 입시반 수업 장면(얼굴 노출 범위 확인), 연습 노트·악보 클로즈업(No.06 표지 후보) |

- 흑백으로 처리하므로 조명만 고르면 휴대폰 사진도 충분합니다. 가로·세로 둘 다 찍어 두면 표지·릴스에 모두 쓸 수 있습니다.
- 얼굴이 나오는 사진은 게시 동의(미성년자는 보호자)를 함께 받습니다.
