# 리서치: II–V–I 진행

## 핵심 개념
- 초보자용: 조성의 2번째 코드 → 5번째 코드 → 1번째 코드로 가는 진행. "준비 → 긴장 → 해결"로 들린다.
- 정확한 설명: 메이저 키에서 IIm7(서브도미넌트 기능) – V7(도미넌트 기능) – IM7(토닉 기능). 근음이 완전4도 상행(=완전5도 하행)으로 두 번 이동하는 도미넌트 모션을 포함한다.

## 슬라이드별 재료
- C 메이저 키 (구성음 직접 확인)
  - Dm7 = D F A C (IIm7, 서브도미넌트)
  - G7 = G B D F (V7, 도미넌트 — B와 F가 트라이톤)
  - Cmaj7 = C E G B (IM7, 토닉)
- 근음 이동: D → G → C, 각각 완전4도 위(= 완전5도 아래)
- 가이드톤(3음·7음) 보이스리딩
  - Dm7(3음 F, 7음 C) → G7(3음 B, 7음 F): C가 B로 반음 하행, F는 유지(Dm7의 3음 → G7의 7음)
  - G7(3음 B, 7음 F) → Cmaj7(3음 E, 7음 B): F가 E로 반음 하행, B는 유지(G7의 3음 → Cmaj7의 7음)
- C 마이너 키 II–V–I
  - Dm7(♭5) = D F A♭ C (IIm7(♭5), 하프디미니시드)
  - G7 = G B D F (실전에서는 G7(♭9) 등 알터드 텐션을 자주 씀)
  - Cm7 = C E♭ G B♭ (Im7 / 곡에 따라 Cm6, CmM7도 사용)
- 다른 키 예시: F 키 = Gm7 – C7 – Fmaj7 / G 키 = Am7 – D7 – Gmaj7
- 12키 연습 순서: 해결 코드의 근음을 완전4도씩 이동 (C → F → B♭ → E♭ → A♭ → D♭ …)

## 예시 곡
- Autumn Leaves (스탠더드): 메이저·마이너 II–V–I가 교대로 등장하는 대표 연습곡
- Fly Me to the Moon: 곡 전체가 II–V–I와 그 변형으로 이어짐
- (가사·악보 인용 없음, 곡명만 언급)

## 흔한 오해 & 정정
- "II–V–I은 재즈에서만 쓴다" → 가요·팝·CCM에서도 흔하다. 단, 콘텐츠에서 "재즈 곡의 80%" 같은 수치는 근거가 없으므로 쓰지 않는다.
- "마이너 II–V–I의 II도 m7이다" → 마이너 키에서는 보통 m7(♭5).
