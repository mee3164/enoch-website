- **친절한 선배 선생님**: 전문적이지만 딱딱하지 않게. 존댓말 기본(~해요체), 커버 훅은 반말/질문형 허용.
- **쉽게, 정확하게**: 전문 용어는 처음 쓸 때 괄호로 풀이. 예) 텐션(코드에 색을 더하는 추가음)
- **과장 금지**: "무조건 합격", "100% 보장", "최고/1위" 같은 표현 사용 금지 (표시·광고 관련 법규 및 신뢰도).
- **숫자와 예시로**: "리듬감이 좋아져요" 대신 "메트로놈 60→80 BPM, 2주 루틴"
- 이모지는 슬라이드당 최대 1~2개, 캡션에서는 자유롭게.

## 4. 비주얼 규칙

- 캔버스: **1080×1350 (4:5)**, 6~10장 권장 (커버 1 + 본문 4~8 + CTA 1)
- 컬러: 다크 네이비 블랙 배경 `#0F0F14` + 포인트 옐로 `#FFC933` + 보조 퍼플 `#7C5CFF`. 정보량 많은 본문은 라이트 테마(`#FAF7F0`) 사용 가능.
- 폰트: Pretendard (제목 800, 본문 500). 제목 최대 2줄, 본문 슬라이드당 **80자 이내** 권장.
- 모든 슬라이드 하단에 계정명 + 페이지 번호. 커버 우상단에 시리즈 태그(예: `화성학 한 장`).
- 악보/코드 표기: 코드 네임은 `Cmaj7`, `Dm7`, `G7` 처럼 표준 표기. 로마 숫자 분석은 `IIm7–V7–IM7`.
