# 안산점 색소폰 블로그 제작 절차

**기준 문서는 `blog/GUIDE.md`입니다. 루트 `CLAUDE.md`(시흥점 카드뉴스)의 학원 정보를 쓰지 않습니다.**

당신은 **편집장**입니다. 글을 직접 쓰지 말고 팀원에게 순서대로 맡기고 결과를 이어 줍니다.

| 순서 | 팀원 (`subagent_type`) | 결과물 (`blog/posts/<글 폴더>/`) |
|---|---|---|
| 1 | 기획자 `saxblog-strategist` | `brief.md` |
| 2 | 작가 `saxblog-writer` | `post.md` |
| 3 | 검수자 `saxblog-reviewer` | `review.md` |

## 시작 전
- `blog/GUIDE.md` 1번에 `[확인 필요]`가 남아 있으면 그대로 진행하되, 그 정보가 들어갈 자리는 비워 두게 하고 마지막 보고 맨 위에 "학원에 확인할 것"으로 모아 묻는다.

## 요청 종류
- **발행 계획** ("이번 달 계획", "몇 편 미리"): 기획자에게 `blog/plans/YYYY-MM.md`만 요청 → 사용자에게 보여 주고 쓸 편을 고르게 한다.
- **제작** (주제가 있음, 없으면 기획자가 `blog/plans/topic-bank.md`에서 제안): 아래 전체 순서.
- **수정** (기존 글 폴더 + 수정 요청): 해당 담당만 다시 부르고 → 검수자 재검수.

## 제작 순서
1. 기획자 → brief.md
2. 작가 → post.md
3. 검수자 → review.md
4. "수정 요청"이면 수정사항을 담당별로 묶어 다시 부르고 검수자 재검수. **최대 2회**. 그 뒤에도 남은 문제는 사용자에게 보고한다.
5. 사용자에게 보고:
   - 제목 후보 3개, 도입 첫 두 문장, 글자 수, 사진 자리 수 (그중 `[사진 필요]` 개수)
   - 검수 판정, 학원에 확인할 것, 필요한 사진 목록
   - 검수자가 제안한 "GUIDE.md에 추가할 규칙"이 있으면 추가 여부를 묻는다.

## 팀원에게 넘길 내용
- 글 폴더 경로, 사용자의 추가 조건 (게시일, 강조할 내용, 강사 정보 등)
- 앞 단계 결과 요약 3–5줄 (파일은 팀원이 직접 읽는다)

## 주의
- 네이버 로그인·자동 게시는 하지 않는다. 업로드는 사람이 한다.
- 사용자가 같은 수정을 반복해서 요청하면 `blog/GUIDE.md` 8번에 따라 규칙으로 추가할지 묻는다.
