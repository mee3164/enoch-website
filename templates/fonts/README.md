# Pretendard (로컬 사본)

- 출처: npm `pretendard@1.3.9` (orioncactus/pretendard), SIL Open Font License 1.1
- CDN이 막힌 환경에서도 같은 글꼴로 렌더링하려고 넣어 둔 woff2 정적 굵기 5종 (Light · Regular · Medium · SemiBold · Bold)
- Caveat (손글씨, 영문): npm `@fontsource/caveat@5.3.0`, SIL Open Font License 1.1 — 캐주얼 스토리용
- DM Serif Display (영문 세리프): npm `@fontsource/dm-serif-display`, SIL Open Font License 1.1 — 작곡과 글쓰기 편 워드마크

- nanum-pen-script/ : 나눔손글씨 펜 (SIL OFL 1.1, @fontsource/nanum-pen-script 5.3.0). 합격 포스터의 손글씨 연도 줄에 쓴다. `400.css`를 link로 불러온다.
