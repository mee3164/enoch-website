# ENOCH 블로그 가이드 (네이버 블로그 · 플레이스)

카드뉴스 팀이 블로그도 같이 만든다. 말투·금지 표현·사실 확인 규칙은 CLAUDE.md를 그대로 따르고, 이 문서는 블로그에만 해당하는 규칙을 적는다.

## 1. 블로그 산출물 (`output/<주제 폴더>/`)

| 파일 | 담당 | 내용 |
|---|---|---|
| `blog.html` → `blog_01.png ~` | 디자이너 | 블로그용 이미지 7–10장 |
| `blog.md` | 카피라이터 | 네이버 블로그 본문 (제목 · 본문 · 이미지 위치 · 태그) |
| `review.md`의 "블로그" 항목 | 검수자 | 아래 4번 체크리스트 |

## 2. 블로그 이미지

- 기준: `output/강사소개_김건우/blog.html`, `output/강사소개_한상희/blog.html`
- 규격 1080 × 1350, 7–10장. 인스타보다 장수를 늘리고, 한 장의 정보는 더 많이 담아도 된다.
- **사진은 1장에만.** 2장부터는 글자 중심(큰 영문 디스플레이, 얇은 선 표, 큰 숫자)으로 만든다.
- 아이보리 / 블랙을 번갈아 쓰고, 마지막 장은 블랙 마무리 (ENOCH 고스트 문자 + 한 줄 + 주소 · 전화 · 과목).
- 2장은 요약 장: 이름(또는 주제) + 핵심 5줄. 블로그는 2장까지만 보고 나가는 사람이 많다.
- 이력·목록은 인지도 순으로 앞에 둔다. 사람들이 이름을 아는 것(아티스트, 방송, 페스티벌, 학교)이 먼저.
- 머리말 `ENOCH MUSIC ACADEMY` / 오른쪽 장 이름, 꼬리말 `<분류> — <주제>` / `02 / 09`.

## 3. 블로그 본문 `blog.md`

```markdown
# 블로그: <주제>

## 제목
<지역 키워드 + 주제, 25–35자>
예: 시흥 실용음악학원 MIDI 레슨 | 김건우 선생님 소개

## 본문
<첫 문단 2–3문장: 핵심 키워드 1회 + 이 글에서만 할 수 있는 이야기(ENOCH이 실제로 하는 일)>

[이미지: blog_01]

## <소제목 1>
<2–3문장 문단을 2–3개>

[이미지: blog_02]
... (소제목 3–5개, 이미지 위치 표시)

## 에녹실용음악학원 시흥점
- 주소: 경기도 시흥시 은행로 157 2층
- 전화: 010 3949 3666
- 운영시간: 평일 13:00–22:00 / 토 10:00–18:00 / 일요일 휴무
- 오시는 길: 대야역 도보 10–15분, 성원아파트 정류장 앞 (1층: 역전우동 · 오피스문구점)
- 과목: Vocal · Guitar · Drum · Bass · Piano · MIDI · 작곡, 모든 과정 1:1 레슨

## 태그 (10–15개)
#시흥실용음악학원 #대야역음악학원 #은행동 ... #에녹실용음악학원
```

- 분량: 본문 1,200–2,500자. 문단은 2–3문장으로 짧게.
- 키워드: "시흥 실용음악학원", "대야역", 과목 + "레슨"을 본문에 자연스럽게 3–5회. 같은 단어를 억지로 반복하지 않는다.
- 카드뉴스 문구를 그대로 옮기지 않는다. 블로그는 카드에 담지 못한 설명(왜, 어떻게, 누구에게)을 더한다.
- 소제목은 질문형이나 짧은 명사형. 이모지·과장 소제목 금지.
- 강사 소개 블로그: 약력은 받은 그대로 옮기되 오타만 고친다. 다른 레슨 스튜디오·학원 이력(대표, 운영)은 넣지 않는다.
- "ENOCH이 이렇게 가르친다"는 확인된 사실만. 원장님은 드러내지 않는다 (CLAUDE.md 3번).

## 4. 검수 체크리스트 (블로그)

- [ ] 제목에 지역 키워드와 주제가 있는가 (25–35자)
- [ ] 첫 문단에 "우리만 할 수 있는 이야기"가 있는가
- [ ] 이미지 위치가 `blog_xx` 파일과 맞는가
- [ ] 학원 정보 블록이 CLAUDE.md 1번과 한 글자씩 같은가
- [ ] 키워드를 억지로 반복하지 않았는가
- [ ] 블로그 이미지: 사진은 1장만, 글자 잘림·겹침 없음, 꼬리말 번호가 맞는가
- [ ] 말투(어미 섞기, "~죠" 없음), 금지 표현 — 인스타와 같은 기준
