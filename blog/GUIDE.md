# ENOCH 네이버 블로그 가이드

에녹실용음악학원 시흥점의 네이버 블로그 글을 만드는 팀(기획 → 작성 → 검수)이 공통으로 읽는 문서다.
각 에이전트는 **이 문서와 자기 단계의 입력 파일만** 읽는다. (카드뉴스용 CLAUDE.md·templates/는 읽지 않는다.)

---

## 1. 학원 정보 (한 글자도 바꾸지 않는다)

- 학원명: 에녹실용음악학원 시흥점 (영문 ENOCH MUSIC ACADEMY)
- 주소: 경기도 시흥시 은행로 157 2층
  - 다른 주소 표기 금지. 이전 주소 '은행동 531-2'는 절대 쓰지 않는다.
- 위치: 대야역 도보 10–15분, 성원아파트 정류장 앞 (1층: 역전우동 · 오피스문구점)
- 전화: 010 3949 3666
- 운영: 평일 13:00–22:00 / 토 10:00–18:00 / 일요일 휴무
- 과목: 보컬 · 기타 · 드럼 · 베이스 · 피아노 · 미디 · 작곡
- 수업: 모든 과정 1:1 레슨 / 입시 · 취미 · 성인 · 전문
- 시그니처 문구: 나만의 진짜 소리를 찾는 곳.

## 2. ENOCH의 원칙 (모든 글의 뿌리)

1. 진도보다 이해를 먼저 봅니다.
2. 같은 곡도, 사람마다 다르게 가르칩니다.
3. 기본은 건너뛰지 않습니다.

- 한 편은 원칙 중 하나와 분명하게 연결된다. 원칙 문장은 위 표기 그대로 인용한다.
- 모든 글은 "왜 이 학원이어야 하는지"가 느껴져야 한다. 분위기가 아니라 가르치는 방식으로 보여 준다.

## 3. 톤과 문장

- 차분하고 진정성 있는 에디토리얼 톤. 합니다체 존댓말.
- 문장은 짧게. 한 문단에 한 가지 이야기. 문단은 2–4문장.
- 추상어 대신 장면. "열심히 가르칩니다" 대신 무엇을 어떤 순서로 하는지.
- 표기: ENOCH 뒤 조사는 '이' — "ENOCH이" (O) / "ENOCH가" (X). "ENOCH은/는"은 그대로 쓴다.
- 마무리는 누구에게나 해당되는 일반론이 아니라, 이 학원에서만 할 수 있는 말로 끝낸다.

### 사실 확인 규칙 (가장 중요)
- "ENOCH에서는 이렇게 가르칩니다"는 **학원에서 확인한 사실만** 쓴다. 확인 전에는 원칙 문장까지만 쓰고, 확인할 내용은 기획안의 "학원에 확인할 것"에 올린다.
- 확인된 항목이라도 방법·순서·기간(몇 주, 몇 분, 어떤 교재)은 확인된 것만 쓴다.
- 악기·이론에 관한 일반적인 설명은 널리 알려진 사실만 쓴다. 불확실하면 빼거나 "보통", "많은 경우"로 범위를 좁힌다.

### 금지
- 단정·과장: 최고, 1위, 유일, 최초, 합격 보장, 100%, 무조건, 완벽한, 특별한, ~의 모든 것
- 근거 없는 수치: "합격률 ○○%", "수강생 ○○명", "○주 만에" 등
- 다른 학원 비교·비방 ("다른 학원과 달리", "흔한 학원들은" 포함)
- 이벤트·할인·마감 임박 같은 자극적인 문구
- 이모지로 시작하는 줄, 이모지 남발, 느낌표 남발
- AI 티가 나는 상투구: "~에 대해 알아보겠습니다", "오늘은 ~을 소개해 드릴게요", "결론적으로", "이상으로 ~였습니다"

## 4. 네이버 검색 키워드

- 메인 키워드 1개 + 서브 키워드 3–5개. 지역 + 과목 + 의도 조합으로 잡는다.
  - 지역어: 시흥, 은행동, 대야동, 대야역, 신천동 (학원 행정동은 은행동)
  - 예: 시흥 실용음악학원, 대야동 보컬학원, 시흥 드럼레슨, 대야역 기타학원
- 메인 키워드는 제목 · 첫 문단 · 소제목 1곳 이상에 **자연스럽게** 넣는다. 본문 전체 3–5회 정도. 같은 문장·인접 문장 반복, 키워드 나열 금지.
- 서브 키워드는 본문과 태그에 각 1–2회.
- 제목은 30자 안팎. 메인 키워드를 앞쪽에 두고, 과장 없이 글의 질문이나 핵심을 담는다.

## 5. 사진

- 실제 사진만 쓴다. AI 생성 이미지·무료 스톡 이미지로 학원 공간, 강사, 학생, 수업 장면을 만들지 않는다.
- 사진은 `blog/posts/<글번호>/photos/`에 미리 넣어 두면 파일명으로 배치한다.
- 사진이 없으면 임의로 채우지 않고, 기획안의 "필요한 사진"에 촬영 요청으로 남긴다. 본문에는 자리만 표시한다.
- 본문 표기: `[사진: 파일명 / 설명]`
  - 파일이 있으면 실제 파일명, 없으면 요청 파일명 (예: `[사진: 03_pad-practice.jpg / 연습 패드 위 스틱을 쥔 손 (촬영 필요)]`)
- 한 편에 사진 4–8장. 첫 사진은 제목 바로 아래(대표 이미지).

## 6. 글 구조와 분량

- 본문 1,500–2,500자 (공백 포함, 사진 표기·안내 블록 제외).
- 도입(독자의 질문이나 장면) → 소제목 3–4개 → ENOCH의 방식(확인된 사실 또는 원칙) → 마무리 → 안내 블록.
- 소제목은 `## ` 한 단계만. 네이버 에디터에서 인용구/소제목으로 바꾸기 쉽게 짧게 쓴다.
- 굵게는 소제목마다 한 곳 이하.

## 7. 파일과 작업 순서

글 한 편의 파일은 모두 `blog/posts/<글번호>/`에 둔다. 글번호는 세 자리 (001, 002 …).

| 순서 | 담당 | 읽는 것 | 만드는 것 |
|---|---|---|---|
| 1 | `blog-planner` (기획·키워드) | GUIDE.md, photos/ 파일 목록 | `plan.md` |
| 2 | `blog-writer` (작성) | GUIDE.md, plan.md, photos/ 파일 목록 | `draft.md` |
| 3 | `blog-editor` (검수) | GUIDE.md, plan.md, draft.md | `review.md` → 승인 시 `final.md` |

- 수정은 검수자가 한 번에 모아 1회만 요청한다. 작성자가 반영하면 검수자가 최종 확인 후 `final.md`를 만든다.
- 여러 편을 요청받으면: 기획은 한 번에(글번호별 plan.md) → 작성은 첫 편 완성·확인 후 나머지를 병렬로.
- 블로그 게시는 사람이 한다. 네이버 로그인·자동 게시는 하지 않는다.

### final.md 형식 (네이버 에디터에 붙여넣기용)

```
# 제목
<제목 한 줄>

# 본문
<본문 — 사진 자리 표시 포함, 마지막에 안내 블록>

# 태그
#태그1 #태그2 … (정확히 10개, 띄어쓰기 없이)
```

- 태그 10개: 메인 키워드 1 + 서브 키워드 + 지역·과목 태그 + #에녹실용음악학원.
- final.md에는 메모·주석·검수 흔적을 남기지 않는다. "학원에 확인할 것"은 plan.md와 review.md에만 둔다.
