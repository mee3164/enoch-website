# ENOCH 네이버 블로그 가이드

에녹실용음악학원 시흥점의 네이버 블로그 글을 만드는 팀(기획 → 작성 → 검수)이 공통으로 읽는 문서다.
각 에이전트는 **이 문서와 자기 단계의 입력 파일만** 읽는다. (카드뉴스용 CLAUDE.md·templates/는 읽지 않는다.)

---

## 0. 블로그의 목표 (모든 판단의 기준)

1. **노출** — 네이버 검색에서 잘 보여야 한다. 키워드·제목·구성은 4번을 따른다.
2. **입시 정보** — 학교별 수시 전형과 일정을 학부모가 한눈에 볼 수 있게 정리한다 (7번).
3. **신뢰** — 이 블로그를 본 학부모, 특히 시흥 지역 학부모가 "입시를 맡겨도 되겠다"고 느끼게 한다.
4. **첫인상** — 입시생뿐 아니라 취미로 배우려는 학생·성인도 글 한 편만 보고 좋은 이미지를 갖게 한다.

그래서 모든 글은 두 가지를 함께 담는다.
- 읽는 사람에게 실제로 도움이 되는 정보 (일정, 준비 방법, 악기 설명)
- 에녹학원이 학생 한 명 한 명을 어떻게 챙기는지 보여 주는 장면 (확인된 사실만)

## 2. ENOCH의 원칙 (모든 글의 뿌리)

1. 진도보다 이해를 먼저 봅니다.
2. 같은 곡도, 사람마다 다르게 가르칩니다.
3. 기본은 건너뛰지 않습니다.

- 한 편은 원칙 중 하나와 연결된다. 원칙 문장은 위 표기 그대로 인용한다.
- "왜 이 학원이어야 하는지"는 분위기가 아니라 가르치는 방식과 챙기는 장면으로 보여 준다.

## 3. 말투 — 원장님의 실제 블로그 말투를 따른다

### 기준 샘플 (원장님이 직접 쓴 글. 이 결을 그대로 따라간다)

```

실제 입시를 앞두고 있는 학생들이
```

### 이 말투의 특징
- **짧은 줄바꿈.** 한 문장을 의미 단위로 2–5줄에 나눠 쓴다. 한 줄은 대략 10–25자. 모바일에서 읽기 편한 호흡이다.
- **문단 사이는 빈 줄.** 한 문단은 한 문장, 길어도 두 문장. 흐름이 크게 바뀌는 곳은 빈 줄을 두 번 둔다.
- **따뜻한 합니다체.** 기본은 "~했습니다 / ~합니다". 설명할 때 가끔 "~답니다", "~수 있어요"처럼 부드럽게 푼다. 딱딱한 논문체나 광고체는 쓰지 않는다.
- **학원이 주어가 되는 약속.** "에녹학원이 함께하겠습니다", "하나씩 제대로 준비하겠습니다"처럼 학원이 무엇을 할지 담담하게 약속한다.
- **학생을 향한 격려.** 학생을 직접 부르며 수고를 인정한다 ("모든 학생들, 정말 수고 많았습니다").
- **짧은 슬로건형 마무리.** "기본기부터 연주, 그리고 실전까지."처럼 명사구로 리듬을 만든 한 줄을 마지막에 둘 수 있다.
- **이모티콘은 가볍게.** 글 전체에 `:)`·😊·👏 같은 것 2–3개까지, 문장 끝에만. 줄 첫머리에 이모지를 두거나 이모지로 목록을 만들지 않는다.
- **느낌표는 절제.** 글 전체 2–3개까지.

### 문장 규칙
- 구체적으로 쓴다. "열심히 가르칩니다" 대신 무엇을 어떤 순서로 하는지.
- 표기: ENOCH 뒤 조사는 '이' — "ENOCH이" (O) / "ENOCH가" (X). 본문에서는 "에녹학원"을 더 자주 쓴다.
- 마무리는 누구에게나 해당되는 일반론이 아니라, 에녹학원이 할 일이나 학생에게 건네는 말로 끝낸다.

### 사실 확인 규칙 (가장 중요)
- "에녹학원에서는 이렇게 가르칩니다", "이런 행사를 했습니다"는 **학원에서 확인한 사실만** 쓴다. 확인 전에는 원칙 문장까지만 쓰고, 확인할 내용은 기획안의 "학원에 확인할 것"에 올린다.
- 확인된 항목이라도 방법·순서·기간(몇 주, 몇 분, 어떤 교재)은 확인된 것만 쓴다.
- 악기·이론에 관한 일반적인 설명은 널리 알려진 사실만 쓴다. 불확실하면 빼거나 "보통", "많은 경우"로 범위를 좁힌다.
- 입시 정보는 7번 규칙을 따른다.

### 금지
- 단정·과장: 최고, 1위, 유일, 최초, 합격 보장, 100%, 무조건, 완벽한, 특별한, ~의 모든 것
- 근거 없는 수치: "합격률 ○○%", "수강생 ○○명", "○주 만에" 등. 합격 실적은 학원이 확인해 준 사실만, 과장 없이.
- 다른 학원 비교·비방 ("다른 학원과 달리", "흔한 학원들은" 포함)
- 할인·이벤트·마감 임박 같은 자극적인 문구
- AI 티가 나는 상투구: "~에 대해 알아보겠습니다", "오늘은 ~을 소개해 드릴게요", "결론적으로", "이상으로 ~였습니다", "~의 중요성"
- 매번 똑같은 3단 나열, 이모지 목록

## 4. 네이버 노출 (키워드·제목·구성)

- 메인 키워드 1개 + 서브 키워드 3–5개. **지역 + 과목/입시 + 의도** 조합으로 잡는다.
  - 지역어: 시흥, 은행동, 대야동, 대야역, 신천동, 시흥 은계 (학원 행정동은 은행동)
  - 입시 예: 실용음악 입시, 실용음악과 수시, ○○대 실용음악과 수시 일정, 시흥 실용음악 입시학원
  - 레슨 예: 시흥 실용음악학원, 대야동 보컬학원, 시흥 드럼레슨, 대야역 기타학원, 시흥 성인 취미 보컬
- 메인 키워드는 제목(앞쪽) · 첫 문단 · 소제목 1곳 이상에 **자연스럽게** 넣는다. 본문 전체 3–5회. 인접 문장 반복·키워드 나열 금지.
- 서브 키워드는 모두 본문에 1회 이상 넣는다. 본문에 넣기 어려운 키워드는 기획 단계에서 서브에서 빼고 태그로만 쓴다.
- 제목은 25–35자. 메인 키워드를 앞에 두고, 검색하는 사람이 궁금한 것을 그대로 담는다.
  - 입시 정보는 학년도와 학교명을 제목에 넣는다 (예: "2027 서울예대 실용음악과 수시 일정 정리").
- 체류 시간을 늘리는 구성: 소제목 3–5개, 사진, 입시 글은 표. 첫 화면(제목 + 대표 사진 + 첫 문단)에서 이 글이 무엇을 알려 주는지 바로 보이게.
- 직접 쓴 사진이 많을수록 좋다. 같은 사진을 다른 글에 반복해서 쓰지 않는다.

## 5. 사진

- 실제 사진만 쓴다. AI 생성 이미지·무료 스톡 이미지로 학원 공간, 강사, 학생, 수업 장면을 만들지 않는다.
- 사진은 `blog/posts/<글번호>/photos/`에 미리 넣어 두면 파일명으로 배치한다.
- 사진이 없으면 임의로 채우지 않고, 기획안의 "필요한 사진"에 촬영 요청으로 남긴다. 본문에는 자리만 표시한다.
- 본문 표기: `[사진: 파일명 / 설명]` — 없는 사진은 설명 끝에 `(촬영 필요)`.
- 학생 얼굴이 나오는 사진은 본인·보호자 동의가 확인된 것만. 확인 전에는 뒷모습·손·악기 위주로 요청한다.
- 한 편에 사진 4–10장. 첫 사진은 제목 바로 아래(대표 이미지).

## 7. 입시 정보 규칙 (학교별 수시 전형·일정)

학부모가 믿고 저장해 두는 글이어야 한다. 틀린 날짜 하나가 신뢰 전체를 무너뜨린다.

- **출처는 해당 대학 입학처의 공식 모집요강(또는 입학처 공지)만.** 커뮤니티·블로그·다른 학원 자료는 출처로 쓰지 않는다.
- 학년도를 반드시 적는다 (예: 2027학년도 수시). 지난 학년도 자료로 올해 일정을 추측하지 않는다.
- 날짜·시간·실기 곡·과제·준비물은 모집요강 원문 그대로 옮긴다. 요약해도 뜻이 바뀌면 안 된다.
- 요강에서 확인하지 못한 칸은 비우지 말고 `요강 확인 필요`로 적는다.
- 경쟁률·합격선 같은 수치는 대학 공식 발표가 있을 때만, 출처와 함께.
- 요약 표를 글 앞쪽에 둔다. 기본 열: `대학 | 전형 | 모집 전공 | 원서 접수 | 실기 고사 | 합격 발표`. 실기 과제는 학교별 소제목 아래에 따로 정리한다.
- 기획안에 출처 URL과 확인한 날짜를 남긴다. 본문 표 아래에 "○월 ○일 각 대학 모집요강 기준" 한 줄을 넣는다.
- 글 끝(안내 블록 위)에 고정 문장: `정확한 내용은 꼭 각 대학 입학처 모집요강에서 한 번 더 확인해 주세요.`
- 모집요강 PDF를 `blog/posts/<글번호>/sources/`에 넣어 두면 기획자는 웹 대신 그 파일을 1순위 출처로 읽는다. (이 환경에서 대학 입학처 사이트가 막혀 있을 수 있다.)
- **이미지:** 입시 정보는 표보다 이미지가 읽기 쉽다. 확인한 값을 `blog/posts/<글번호>/exam.json`에 넣고 `node blog/scripts/render-exam.mjs blog/posts/<글번호>`로 `images/01.png ~`를 만든다 (폭 1080, 표지 → 일정 요약 → 학교별 → 마무리). 본문에는 `[사진: images/03.png / 서울예대 전형·일정 정리]`처럼 배치한다.
- 에녹학원의 입시 준비 방식(모의고사, 실기 곡 선정, 레슨 방식 등)은 학원이 확인해 준 것만 쓴다. 모의고사처럼 이미 블로그에 올린 행사는 사실로 쓸 수 있다.

## 8. 파일과 작업 순서

글 한 편의 파일은 모두 `blog/posts/<글번호>/`에 둔다. 글번호는 세 자리 (001, 002 …).

| 순서 | 담당 | 읽는 것 | 만드는 것 |
|---|---|---|---|
| 1 | `blog-planner` (기획·키워드) | GUIDE.md, photos/ 파일 목록, (입시 글) 대학 모집요강 | `plan.md` |
| 2 | `blog-writer` (작성) | GUIDE.md, plan.md, photos/ 파일 목록 | `draft.md` |
| 3 | `blog-editor` (검수) | GUIDE.md, plan.md, draft.md | `review.md` → 승인 시 `final.md` |

- 수정은 검수자가 한 번에 모아 1회만 요청한다. 작성자가 반영하면 검수자가 최종 확인 후 `final.md`를 만든다.
- 여러 편을 요청받으면: 기획은 한 번에(글번호별 plan.md) → 작성은 첫 편 완성·확인 후 나머지를 병렬로.
- 블로그 게시는 사람이 한다. 네이버 로그인·자동 게시는 하지 않는다.

### final.md 형식 (네이버 에디터에 붙여넣기용)

```
# 제목
<제목 한 줄>

# 본문
<본문 — 줄바꿈 그대로, 사진 자리 표시 포함, 마지막에 안내 블록>

# 태그
#태그1 #태그2 … (정확히 10개, 띄어쓰기 없이)
```

- 태그 10개: 메인 키워드 1 + 서브 키워드 + 지역·과목/입시 태그 + #에녹실용음악학원.
- final.md에는 메모·주석·검수 흔적을 남기지 않는다. "학원에 확인할 것"은 plan.md와 review.md에만 둔다.
