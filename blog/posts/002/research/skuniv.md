## 1. 모집단위

- 정식 명칭: 공연예술대학 **실용음악학부** (p.11)
- 전공: 보컬전공, 싱어송라이터전공, 작곡전공, 기악전공[관악, 베이스, 드럼, 기타, 피아노]. 기악전공 관악의 세부악기는 **색소폰, 트럼펫, 트럼본**을 모집 (p.11 각주 ④)
- 캠퍼스: 요강에 캠퍼스 구분 없음. 서류 접수처 주소는 서울시 성북구 서경로 124 (정릉동) 서경대학교 입학처 (p.18)
- 학과 사무실: 실용음악학부 02-940-7795 (p.56)
- 기악전공·작곡전공은 ♣ 표시 = 수시 100% 모집(수시 결원 시 정시로 이월). 보컬·싱어송라이터에는 ♣ 표시 없음 (p.11)
- 참고: 같은 대학 '음악학부'(피아노·관현악)는 클래식 전공이라 이 조사에서 뺐다.

## 2. 전형과 모집인원

- 실용음악학부가 모집하는 수시 전형은 **실기우수자 전형(정원내) 하나**. 다른 전형(논술·교과·기회균형 등)에는 실용음악학부 모집인원이 없음 (p.11)
- 실기우수자 전형 모집인원 (p.11)

| 전공 | 인원 |
|---|---|
| 기악 – 관악 | 3 |
| 기악 – 베이스 | 5 |
| 기악 – 드럼 | 5 |
| 기악 – 기타 | 7 |
| 기악 – 피아노 | 6 |

- 지원자격: 고등학교 졸업(예정)자 또는 동등 학력 인정자 (p.19). 관련분야 자격증 소지 여부와 관계없이 지원 가능 (p.21)

## 3. 전형 요소·반영 비율·단계별 선발

- 단계별 전형 (p.19)
  - 1단계: 실기고사 100%
  - 2단계: 학생부(교과) 20% + 실기고사 80% (표의 '1단계 성적' 칸은 실용음악학부 행에서 비어 있음)
- 1단계 선발비율 (p.20)
  - 기악전공 400%
  - 작곡전공 500%
  - 보컬전공/싱어송라이터전공 400%
  - 1단계 합격선 동점자는 모두 2단계 응시자로 선발
- 실기 반영배점: 1단계 1,000점, 2단계 800점 (p.24)
- 과락제: 실기고사 성적이 모집단위별 기준점수 미만이면 모집인원과 관계없이 불합격. 단계별 전형에도 모두 적용 (p.19)
- 실기고사 결시자·부정행위자, 서류 미제출자는 불합격 (p.19)
- 학생부 반영: 국어 25 / 영어 25 / 수학 25 / 한국사·사회·과학 25, 각 상위 3과목 (p.20)
- 동점자: ① 실기고사 점수 상위자 → ② 학생부 국·영·수 성적 상위자 … (p.20)
- 학교폭력 조치사항: 4호–9호는 총점(1,000점)에서 50점 감점, 1–3호 감점 없음 (p.50)
- 전형료: 실기우수자 1·2단계 모집단위 110,000원. 1단계 불합격자는 30,000원 12월 말 자동 반환 (p.51)

## 6. 전공별 실기 과제 (p.24)

### 공통사항
- 반주곡은 USB에 확장자 **.mp3**인 입시곡만 저장해 고사 당일 제출. USB는 바이러스 예방을 위해 **새 제품만** 사용
- **2단계 곡은 1단계 곡과 중복되지 않는 다른 곡**이어야 함
- 기타 이펙터는 고사장 내 드라이브만 사용 가능, 베이스 이펙터 사용 불가
- 실기 후 추가곡, 초견, 질의응답 등의 시간이 있을 수 있음
- 심사위원용 악보 제출(반환하지 않음): 사전 준비, 교내 인쇄 불가. A4 사이즈(인적사항, 학원명, 특수기호 등 기재 불가). **1단계 3부, 2단계 5부**

### 기악전공 (관악·베이스·드럼·기타·피아노)
- 1단계: 자유곡ⓐ 1곡 (1,000점) / 2단계: 자유곡ⓑ 1곡 (800점)
- 암보로 3분 내외. 반주자 동반 시 1명으로 제한
- 피아노, 드럼, 앰프를 제외한 악기 본인 지참. 고사장 내 드럼세트만 사용 가능
- 기타·베이스전공은 전공악기 개인 스트랩 필수 지참

### 작곡전공
- 1단계: 자유곡ⓐ 1곡 (1,000점) / 2단계: ①자유곡ⓑ 1곡 + ②자작곡 1곡 (800점)
- 암보 3분 내외, 본인 직접 연주만 가능 (MR 음원 불가, 반주자는 보컬만 가능)
- 피아노 또는 어쿠스틱기타 중 선택 (기타는 본인 지참)

### 보컬전공
- 1단계: 자유곡 1곡 (1,000점) / 2단계: 한글 가사곡 1곡 (800점)
- 암보로 2분 내외. 반주자 동반 시 1명으로 제한
- 반주는 피아노 또는 어쿠스틱기타로 제한 (본인 반주 가능)
- 한글 가사곡: 자유곡
- (공통사항의 .mp3 반주곡 제출 문구와 보컬의 '피아노·어쿠스틱기타 반주 제한' 문구가 함께 적혀 있음. 보컬이 MR을 쓸 수 있는지는 요강에 명시 없음 → 학과 확인 권장)

### 싱어송라이터전공
- 1단계: 자유곡 1곡 (1,000점) / 2단계: 자작곡 1곡 (800점)
- 암보로 2분 내외, 자가반주만 가능
- 자가반주는 피아노 또는 어쿠스틱기타로 제한

## 7. 준비물

- 수험표(원서접수 후 출력) + 신분증 (p.13, p.15, p.17)
  - 인정 신분증: 주민등록증, 청소년증, 운전면허증, 여권, 카드형 또는 압인형 학생증. 분실 시 '주민등록증 발급 신청 확인서'(관할 주민센터 발급) (p.15)
- 반주곡: 새 USB에 .mp3 입시곡만 저장, 고사 당일 제출 (p.24)
- 심사위원용 악보 A4: 1단계 3부, 2단계 5부, 미리 인쇄 (p.24)
- 악기: 피아노·드럼·앰프 외 본인 지참 / 기타·베이스는 개인 스트랩 필수 / 작곡 어쿠스틱기타 선택 시 본인 지참 (p.24)
- 고사 중 휴대전화·무선송신기 등 휴대 금지, 위반 시 퇴실 (p.15)
- 예비소집 없음 (p.13, p.15)

## 8. 헷갈린 점·확인 필요

- 실용음악 관련 전형은 실기우수자 하나뿐이라 전형 혼동은 없음.
- 전공별 실기 날짜: 요강에는 학부 전체 범위(1단계 10.3–10.17)만 있음. 전공별 날짜는 9.23 홈페이지 세부일정 공지 확인 필요.
- 보컬 반주: 공통사항(.mp3 반주곡 USB 제출)과 보컬 항목(피아노·어쿠스틱기타 반주 제한)이 함께 있어 MR 사용 가능 여부가 문장만으로는 분명하지 않음.
- 기악 관악 세부악기는 색소폰·트럼펫·트럼본만 모집.
