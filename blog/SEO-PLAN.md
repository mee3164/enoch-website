# 네이버 상위노출 로드맵 (2026-10 → 2026-12)

목표: 2026년 안에 "시흥 + 과목" 핵심 키워드에서 블로그 첫 페이지 노출.
기준 문서: `blog/GUIDE.md` (말투·사실 확인 규칙은 노출보다 우선한다).

## 원칙

1. **한 글 = 메인 키워드 하나.** 같은 메인 키워드로 두 번 쓰지 않는다 (내 글끼리 경쟁). 순위가 안 오르면 같은 키워드를 다시 쓰지 말고, 아래 "받침 글"로 보강한다.
2. **과목 핵심 키워드 먼저, 동네 키워드는 그다음.** "시흥 ○○학원"을 먼저 깔고, "대야동·은행동·대야역 ○○학원"은 받침 글로 잇는다.
3. **주 2–3편, 꾸준히.** 몰아서 올리기보다 간격이 일정한 것이 블로그 신뢰도에 좋다.
4. **글마다 직접 찍은 사진 8–10장 + 네이버 지도.** 사진은 글끼리 겹치지 않게 (GUIDE.md 4번).
5. **문장 틀을 반복하지 않는다.** 같은 구조여도 소제목·Q&A·문장은 매번 새로 쓴다 (유사문서 방지).
6. **게시 후 7일, 21일에 순위 확인** → 아래 표의 "순위" 칸에 기록. 21일 뒤에도 첫 페이지 밖이면 받침 글 1편 추가.
