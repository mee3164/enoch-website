# ENOCH 레슨 포장 전략 (2026-10-10)

> 원장님 고민: 선생님들의 실력은 상향 평준화됐다. 서비스도 어디나 비슷하다. 그래서 차이는 "어떻게 보이느냐(인식)"에서 난다.
> 이 문서는 ENOCH 레슨을 고급스럽게 보이게 하는 방법을 정리한다. 블로그·카드뉴스·플레이스에서 공통으로 쓴다.
> 사실 확인 규칙(GUIDE 1번, CLAUDE.md 3번)은 이 문서보다 우선한다. 포장은 있는 것을 잘 보이게 하는 일이다. 없는 것을 만들어 내지 않는다.

---

## 1. 핵심: 사람이 아니라 "형식"을 판다

선생님 실력이 비슷하면 "우리 선생님이 잘 가르쳐요"는 차별점이 되지 못한다. 어느 학원이나 하는 말이기 때문이다.
고급 브랜드가 평범한 물건을 비싸게 보이게 하는 방법은 거의 같다.

| 고급 브랜드가 하는 일 | 예시 | ENOCH에 옮기면 |
|---|---|---|
| **이름을 붙인다** | "커피" → "싱글 오리진 핸드드립" | "레슨" → **ENOCH 1:1 레슨**. 과정마다 이름이 있는 한 단위 |
| **구성품을 보여 준다** | 제품 박스의 "구성품" 목록 | 레슨 한 번에 들어 있는 것을 **명세서처럼** 나열한다 |
| **순서(의식)를 보여 준다** | 오마카세의 코스 순서 | 첫 방문 → 체험 40분 → 등록 → 녹음 → 연습실로 이어지는 **흐름** |
| **기록을 남긴다** | 맞춤 정장의 치수 카드 | 녹음된 **내 소리**가 남는다 (보컬, 확인됨) |
| **말을 줄인다** | 가격표 없이 여백 넓은 진열 | 형용사 없이 **짧은 사실 + 넓은 여백** |
| **일관성** | 어느 매장이든 같은 톤 | 모든 이미지에 같은 머리말·서체·아이보리 (이미 갖춤) |

정리하면 이렇다. 고급스러움은 "좋다"고 말해서 생기지 않는다. **정해진 형식이 있다는 것이 보일 때** 생긴다.

## 2. 지금 바로 쓸 수 있는 포장 재료 (확인된 사실만)

| 재료 | 포장 문장 예시 |
|---|---|
| 모든 과정 1:1 | "한 시간에 한 사람. 수업이 그 사람의 속도로 갑니다." |
| 원칙 3가지 | "진도보다 이해를 먼저 봅니다." 원칙은 그대로 브랜드 문장으로 쓴다 |
| 보컬 레슨 녹음 | "수업이 끝나도 내 소리가 남습니다." |
| 콘덴서 마이크·팝필터·헤드폰·스피커 | 사진으로 클로즈업. 장비 이름은 쓰고, 가격·브랜드 자랑은 하지 않는다 |
| 연습실 하루 1시간 (수강생) | "레슨이 없는 날에도 들를 곳이 있습니다." |
| 체험 레슨 1:1 40분 | 체험을 "판매"가 아니라 **"첫 만남 40분"**으로 부른다 |
| 학원 기타·스틱 대여 | "빈손으로 오셔도 됩니다." |

## 3. 콘텐츠 시리즈 5개

1. **THE ENOCH LESSON — 레슨 명세서**
   - 레슨 하나를 제품 구성품처럼 보여 주는 한 장짜리 이미지.
   - 블로그 모든 글 하단, 플레이스 대표 사진, 인스타 고정 게시물에 쓴다.
   - 시안: `blog/assets/academy/lesson-spec.png` (`node blog/scripts/render-lesson-spec.mjs`)
2. **첫 만남 40분 — 체험 레슨을 코스처럼**
   - 들어와서 나갈 때까지의 40분을 순서로 보여 준다.
   - ⚠️ 체험 40분의 실제 순서는 학원에 확인해야 한다 (아래 질문 1).
3. **소리 기록 — 녹음으로 남는 것**
   - 보컬 녹음 장면 사진 + "내 소리를 처음 들었을 때" 이야기.
   - 학생 얼굴·목소리를 쓰려면 동의가 필요하다. 마이크에 가려진 사진 방식이 좋다 (008과 같은 방식).
4. **원칙 3부작 — ENOCH이 하지 않는 것**
   - "진도를 빼지 않습니다 / 같은 곡을 같은 방식으로 가르치지 않습니다 / 기본을 건너뛰지 않습니다".
   - "하지 않는 것"을 말하는 브랜드가 더 고급스럽게 읽힌다.
5. **디테일 클로즈업 — 공간과 도구**
   - 마이크, 팝필터, 연습실 문, 악보대, 조명.
   - 사람 없이 사물만 찍은 사진으로 한 장에 한 컷, 문장 한 줄.
   - 사진만 있으면 바로 만들 수 있다.

## 4. 하지 말 것

- "프리미엄", "명품 레슨", "최고급" 같은 직접 표현. 고급이라고 말하는 순간 고급이 아니게 된다.
- 할인을 크게 쓰는 것. 체험 금액은 작은 글씨로 차분하게 쓴다 (GUIDE 3번).
- 확인 전의 수업 순서·방법을 "ENOCH 방식"으로 포장하는 것.

## 5. 학원에 확인할 것 (답을 주시면 포장 재료가 늘어납니다)

1. 체험 레슨 40분은 실제로 어떤 순서로 진행되나요? (예: 상담 → 소리 듣기 → 짧은 수업 → 방향 안내)
2. 첫 수업 때 학생마다 하는 것이 있나요? (목표 상담, 수준 확인 등)
3. 수업 내용을 학생에게 남겨 주나요? (레슨 노트, 녹음 파일 공유, 연습 과제 등)
4. 보컬 말고 다른 과목도 녹음·영상 기록을 하나요?
5. 정기 발표회·무대·합주 같은 자리가 있나요?
6. 레슨 1회 시간과 한 달 횟수는 어떻게 되나요?

1–3번이 확인되면 "ENOCH의 첫 수업"과 "레슨 노트"를 이름 붙은 형식으로 만들 수 있다. 이 두 가지가 포장 효과가 가장 크다.
