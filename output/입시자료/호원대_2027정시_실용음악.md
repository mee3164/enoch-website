# 호원대학교 2027학년도 정시 — 실용음악학부 요약

출처: 호원대학교 2027학년도 정시모집('가', '나'군) 신입생 모집요강 (2026-08 판), 요강 1–19쪽. 2026-11-10 정리.
콘텐츠에 쓸 때는 반드시 최신 요강을 다시 확인한다. 수시 결원은 정시에서 선발하므로 인원이 늘 수 있다.

## 기본
- 실용음악학부는 **'나'군**
- 산업대학교라 정시 지원 횟수 제한 없음, 수능 최저기준 없음
- 학교 안에서는 1개 학부(과)만 지원 가능
- 수시 합격자(충원 포함)는 등록 여부와 관계없이 정시 지원 불가
- 실기고사는 서울 성내동 호원취업지원센터, 수업은 군산 본교

## 선발 방법 (실질반영비율, 수능 미반영)
- 보컬·사운드테크놀로지 외 전공: 학생부 28.6% + 실기 71.4% (한 번에 선발)
- 보컬: 1단계 실기 100% → 2단계 학생부 28.6% + 실기 71.4%
- 사운드테크놀로지: 1단계 실기 100% → 2단계 학생부 25.5% + 실기 63.8% + 필기 10.6%
- 학생부: 1학년 30% · 2학년 40% · 3학년 30%
- 학교폭력 조치사항은 호수별 감점 (1호 -10점 … 9호 -50점)

## 실기 내용 (모두 암보, 반주자는 악보 봐도 됨)
- **보컬** (단계별): 1차 자유곡 1곡 / 2차 발라드 1곡 + 리듬 있는 곡 1곡. MR(휴대폰) 또는 반주자 동반(1차는 드럼 반주 불가), 자가반주·무반주 가능. MR에 코러스 금지(뮤지컬 곡 제외), 전주는 5초 이내로 편집
- **싱어송라이터**: 자작곡 2곡 본인 연주, 가사 각 3부 제출. 반주자·MR 불가
- **피아노**: 자유곡 2곡 + 단선율 청음 · 음정 청음
- **드럼**: 자유곡 1곡. 스네어·심벌·페달 등 개인 장비 지참 불가 (트윈페달만 가능)
- **베이스**(일렉·콘트라): 자유곡 1곡. 스탠다드는 헤드 멜로디 생략하고 리듬부터 연주 권장
- **기타**: 자유곡 1곡. 오버드라이브 · 퍼즈 · 디스토션 중 이펙터 페달 1개만(배터리 전원)
- **그 외 악기**(퍼커션 포함): 자유곡 1곡, 관·현악·국악 모두 가능. 봉고·콩가·팀발레스 제공
- **파퓰러뮤직프로덕션**: DAW로 만든 가창곡 1곡 + 제작설명서, 악보(멜로디·가사·코드) 3부
- **영상음악프로덕션**: DAW로 만든 영화·드라마 OST 자작곡 1곡 + 코드심볼 포함 총보 + 곡 설명서
- **일렉트로닉뮤직프로덕션**: DAW로 만든 전자음악 자작곡 1곡 + 제작설명서 + 피아노 자유곡 1곡. 2마디 이상 샘플 사용 불가
- **사운드테크놀로지** (단계별): 1차 직접 녹음한 트랙을 믹싱·마스터링한 음원 1곡 + 제작설명서 / 2차 사운드 분석·청음 + 필기(음향이론 객관식·서술식)

### 프로덕션 공통
- 음원 1분 30초 ~ 2분 30초, WAV(24bit 48kHz), 제작설명서 A4 3쪽 이하 PDF, USB로 당일 제출, 개인정보 기재 금지
- 기존 곡과 비슷하거나 AI를 쓴 경우, 다른 사람 도움·협업이 있으면 합격 취소. **모든 자작곡 AI 사용 금지**
- 음원을 틀고 실연·가창 불가

### MR 준비
- 반드시 휴대폰에 다운로드해 두기. 스트리밍 절대 불가(비행기 모드로 재생)
- USB·CD 불가(일부 전공 제외), 태블릿 불가, 3.5mm 출력 기기 가능, 아이폰·USB-C 젠더는 고사장에 있음
- 피아노 · 드럼 · 앰프 외 악기·장비는 본인 지참
- 예약 시간 30분 전까지 입실, 심사위원 재량으로 단축·추가곡 가능
