# 성신여자대학교 2027학년도 정시 — 현대실용음악학과 요약

출처: 2027학년도 성신여자대학교 정시 신입생 모집요강, 요강 15–39쪽. 2026-11-11 정리.

- 같은 군 안의 대학끼리는 복수지원 불가, 수시 합격자는 정시 지원 불가

- 학생부 미반영

## 실기 (2분 내외, 암보)
### 보컬
- 자유곡 1곡 (자신의 개성과 장점이 가장 잘 드러나는 곡)
- 악보 제출 없음
- 반주 MR, 자가반주, 무반주 가능. **반주자 동행 불가**
- 피아노 외 반주 악기는 본인 지참

### 악기 (피아노 · 기타 · 베이스기타 · 드럼)
- 자유곡 1곡, 악보 제출 없음
- 피아노 외 악기는 반주 MR 사용 가능, **반주자 동행 불가**
- 피아노 · 드럼 외 악기는 본인 지참
- 노래 불가, 기타 · 베이스기타는 **이펙터 사용 금지**

### MR 유의사항
- MP3는 원서접수 후 1.8.(금) 18:00까지 원서접수 사이트에 업로드
- 고사 때 MR 시작 구간을 고를 수 없음 → 파일 자체를 시작점에 맞춰 편집해서 올릴 것
