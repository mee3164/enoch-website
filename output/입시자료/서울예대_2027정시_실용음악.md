## 선발 방법 (일반전형 실기우수)
- 1차: 실기만으로 모집인원의 3배수 내외 선발
- 최종: 2차 실기 70%(700점) + 수능 30%(300점). 1차 성적은 최종 성적에 반영하지 않음
- 수능 반영 영역: 국어 · 수학 · 영어 (등급 환산: 1등급 300 … 9등급 72, 등급 간 28.5점)
- 수능 미응시자도 지원 가능 (9등급 성적 반영)
- 2차 필답시험 미응시자는 불합격

## 실기 내용
### 공통 (노래·작곡·연주)
- 반주는 [반주음원 / 반주자 1인 / 무반주 / 본인 반주] 중 곡마다 하나만. 다른 수험생의 반주자로는 참여 불가
- 반주음원은 원서접수 때 mp3(10MB 이하, 256k 이상 권장)로 업로드 + 시험 당일 USB(윈도우 포맷)로도 지참. 노래 2차는 USB만 가능
- 곡당 악보 5부(A4 세로), 포트폴리오 제출 금지, 마이크 설치됨
- 피아노·드럼·앰프 외 악기는 본인 지참, 악기용 액세서리 사용 불가
- 작곡·연주는 1·2차 모두 초견 연주 질문이 있을 수 있음
- 필답시험은 연필·지우개 지참 (볼펜 사용 시 0점)

### 노래
- 1차: 자유곡 2곡(한 곡당 1분 이내) — 가요(한국어) 1곡 + 팝(외국어) 1곡, 리듬과 템포가 서로 다른 2곡
- 2차: 필답 실용음악통론(40분) + 자유곡 2곡(같은 조건)·시창·구두문답(5분 내외)

### 작곡
- 1차: 코드작곡 1곡 연주(악기로만) + 자작곡 연주(악보 제출) + 구두문답(5분 내외)
- 2차: 필답 실용음악통론(40분) + 필답 전통화성학(60분) + 자작곡·코드작곡 연주 및 구두문답(5분 내외)

### 연주 (드럼·베이스·기타·피아노·관악 등)
- 1차: 자유곡 1곡(2분 내외), 창작곡·기성곡 모두 가능
- 2차: 필답 실용음악통론(40분) + 자유곡 1곡 연주·구두문답(5분 내외)
- 기타는 기성곡의 원곡 솔로를 그대로 재현하면 안 됨 (본인이 만든 솔로나 즉흥 솔로만)

### 전자음악 / 음향디자인 / DJ
- 반주자 대동 불가. 지참 악기는 어쿠스틱 악기(일렉 기타·베이스 포함)만, 신디사이저·컨트롤러·컴퓨터 반입 불가. 종이 악보 제출 불가
- 전자음악: 원서접수 때 자작곡 1곡 음원 + 작품설명 PDF(A4 3쪽 이내) 업로드. 1차 자유곡 연주(1분) + 자작곡 구두문답(5분). 2차 필답 2개 + 자유곡 + 구두문답
- 음향디자인: 1차 자유곡(1분) + 음향기초 구두문답·믹싱콘솔 과제(Midas M32). 2차 필답 2개 + 자유곡 + 오디오 이론·콘솔·마이크 구두문답과 과제
- DJ: 원서접수 때 자작곡 믹스 파일 1개 업로드. 1차 자유곡 + Pioneer XDJ-RX2로 자작곡 2곡 이상 믹싱(1분) + 구두문답(8분). 2차 필답 2개 + 자유곡 + DJing
- 자작곡에 AI 사용 시 학교 세부 지침 범위 안에서, 작품설명에 반드시 기재
