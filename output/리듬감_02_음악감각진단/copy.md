- 시리즈: 리듬감 시리즈 #1 = `output/입시_리듬_정박/` (정박의 중력) → #2 이 편 → #3 악기별 리듬감(예정)
- 연결 원칙: 2 "같은 곡도, 사람마다 다르게 가르칩니다." (진단 → 사람마다 다른 개선)
- 원장님 교육 철학(확인된 문장): "선생님은 진단을 내리고, 그것을 보완하고 고쳐 나갈 방법을 이해하기 쉽게 설명하는 것이 역할"
- 화자: ENOCH. 개선 가이드는 일반 연습법으로 표기 (ENOCH 수업 방식이라고 단정하지 않음).
- 박자감과 리듬감 구분: 박자감 = 템포·박의 위치를 지키는 감각 / 리듬감 = 음의 길이·강약·무게로 흐름을 만드는 감각 (#1 "박자는 맞는데 리듬이 안 산다"와 이어짐)

## 01 문제 제시
- kicker: RHYTHM SERIES #2
- 제목: 뭐가 부족한지는 아는데,\n정확히 뭘 고쳐야 할까요?
- 본문: "리듬이 약해", "감이 없어". 이런 말만으로는 무엇부터 연습할지 알기 어려워요. 막연한 느낌을 항목으로 나눠 보는 것, 그게 진단이에요. 진단은 평가가 아니라 출발점이에요.
- 한 문장: 막연한 부족함을 항목으로 나누면, 고칠 곳이 보여요.

## 02 진단 항목 네 가지
- kicker: FOUR SENSES
- 제목: 음악 감각,\n네 가지로 나눠 봐요
- 항목 (정의 / 입시에서)
  1. 박자감 — 템포를 일정하게 지키고, 박의 위치를 아는 감각. / MR과 함께하는 실기의 바탕이에요.
  2. 리듬감 — 음의 길이·강약·무게로 흐름을 만드는 감각. / 같은 박자 안에서 '살아 있는 연주'를 가르는 차이예요.
  3. 음정감 — 음의 높낮이를 정확히 듣고 유지하는 감각. / 짧은 실기에서도 작은 어긋남이 바로 들려요.
  4. 음악성 — 셈여림·프레이즈·음색으로 곡을 표현하는 힘. / 기술 위에 나만의 소리를 얹는 부분이에요.
- 한 문장: 박자감·리듬감·음정감·음악성, 네 가지로 나누면 진단이 구체적이 돼요.

## 03 자가진단 체크리스트 1/2 — 박자감 · 리듬감
- kicker: SELF-CHECK 1/2
- 제목: 나에게 해당하는지\n체크해 보세요
- 박자감
  - [ ] 음악을 틀면 1·2·3·4를 바로 셀 수 있다
  - [ ] 메트로놈을 끄고 1분 연주해도 템포가 그대로다
  - [ ] 쉼표에서도 박을 놓치지 않는다
  - 약하다면 → 메트로놈 소리를 2·4박에만 남기고, 나머지 박을 스스로 채워 봐요.
- 리듬감
  - [ ] 박자는 맞는데 "딱딱하다"는 말을 들은 적이 없다
  - [ ] 정박과 사이 음의 무게를 다르게 칠 수 있다
  - [ ] 8분음표를 스트레이트와 셔플로 바꿔 칠 수 있다
  - 약하다면 → 리듬감 시리즈 #1의 무게 이동 연습(발 → 목소리 → 악기)부터 해 봐요.
- 한 문장: 체크되지 않는 칸이, 지금 연습할 곳이에요.

## 04 자가진단 체크리스트 2/2 — 음정감 · 음악성 + 결과 해석
- kicker: SELF-CHECK 2/2
- 제목: 체크가 적어도\n괜찮아요
- 음정감
  - [ ] 기준음을 듣고 같은 음을 바로 찾을 수 있다
  - [ ] 소리 내기 전에 다음 음을 머릿속으로 불러 볼 수 있다
  - [ ] 녹음을 들으면 어긋난 음을 스스로 찾아낸다
  - 약하다면 → 피아노나 튜너로 기준음을 듣고, 녹음해서 어긋난 음을 표시해 봐요.
- 음악성
  - [ ] 같은 구절을 두 번 칠 때 표현을 다르게 할 수 있다
  - [ ] 숨 쉬는 자리, 프레이즈의 끝을 알고 연주한다
  - [ ] 곡이 무엇을 말하는지 한 문장으로 설명할 수 있다
  - 약하다면 → 좋아하는 연주를 한 구절씩 따라 하며, 셈여림과 호흡을 비교해 봐요.
- 메시지: 진단은 점수가 아니라, 어디서 시작할지 알려 주는 지도예요.
- 한 문장: 비어 있는 칸은 부족함이 아니라, 시작할 자리예요.

## 05 정리 + 다음 단계
- kicker: THE ENOCH WAY
- 제목: 진단 다음은,\n이해와 개선이에요
- 본문: ENOCH에서 선생님의 역할은 진단을 내리고, 보완하고 고쳐 나갈 방법을 이해하기 쉽게 설명하는 거예요. 진단 → 이해 → 개선. 모든 과정이 1:1 수업이라, 같은 진단도 사람마다 다른 방법으로 풀어 가요.
- 다음 이야기: 리듬감 시리즈는 계속돼요. (2026-10-05: #3 계획은 있으나 바뀔 수 있어 주제는 밝히지 않음)
- 한 문장: 진단에서 끝나지 않고, 이해와 개선까지 함께 가요.
