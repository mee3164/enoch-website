# 구성안: ENOCH NOTE — 환경과 선생님

주제(원장님 요청 2026-10-12): 사람은 환경에 지배를 받는다. 좋은 음악을 하려면 음악하기 좋은 장소와 좋은 선생님을 만나는 것도 꽤 중요하다.
형식: ENOCH NOTE 에세이, 정렬선 디자인(`노트_몸과노래/deck_line.html` 결). 7장.

| 장 | 역할 | 핵심 메시지 |
|---|---|---|
| 01 | 표지 | 연습이 안 되는 건, 정말 의지 탓일까? (원장님 선택 10/12) |
| 02 | 환경 | 사람은 환경을 닮아 간다 (의지만큼 환경이 습관을 만든다) |
| 03 | 장소 | 음악하기 좋은 곳 = 소리 내기 편한 곳 |
| 04 | 선생님 | 좋은 선생님 = 내 소리를 듣는 사람 |
| 05 | 계속 | 장소와 사람이 맞으면 오래 하게 된다 |
| 06 | ENOCH | 확인된 사실만: 분위기 / 연습실 / 모든 과정 1:1 |
| 07 | 마무리 | 좋은 소리는 좋은 자리에서 + 원칙 2 |

- "지배"는 세게 들려서 "닮아 간다"로 풀었다.
- 강사 수·평수·방 개수, 강사 자랑("최고의 강사진")은 쓰지 않았다.
- 기존 `환경의_중요성`(10/16, 사진 재촬영 보류)과 주제가 겹친다. 이 편이 대신하면 그 편은 접어도 된다.
