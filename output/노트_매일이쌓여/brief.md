# 매일이 쌓여 내가 된다 — 구성안 (문구 확인 전, 카드 출력 전)

- 주제: 매일의 연습이 쌓여 내가 된다 + 마음이 흔들리는 사람을 위한 글귀 ("지금 잘하고 있어요")
- 연결 원칙: 2. 같은 곡도, 사람마다 다르게 가르칩니다.
- 우리만 할 수 있는 이야기: 수강생은 운영시간 안에 연습실을 자유롭게 이용 (4장)

| 장 | 레이아웃 | 핵심 |
|---|---|---|
| 01 | photo | 매일이 쌓여, 내가 됩니다. |
| 02 | point | 하루치 연습은 작아서 안 보일 뿐 |
| 03 | point (blush) | 흔들리는 날에도, 여기까지 왔습니다 — 지금, 잘하고 있어요 |
| 04 | steps (black) | 오늘을 쌓아 두는 법: 한 줄 기록 · 30초 녹음 · 일주일 뒤 듣기 |
| 05 | point | 비교는 어제의 나와만 |
| 06 | closing (black) | 매일이 쌓여, 내가 됩니다. |
