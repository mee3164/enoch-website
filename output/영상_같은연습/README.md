# 칠판 설명 영상 — 같은 연습, 다른 결과

- 진행: 에녹이 (`../디어에녹_01_무대떨림/mascot.py`)
- 규격: 1080×1920 (릴스), 22.5초, 30fps, 소리 없음 → 음악·내레이션은 캡컷에서 얹기
- 근거: Duke, Simmons & Cash (2009) — 피아노 전공생 17명의 연습 관찰. 잘 친 사람은 연습 시간이 아니라 틀린 곳을 바로 찾아 고치는 방식에서 달랐다.

## 장면·자막 (내레이션 대본으로 그대로 써도 됨)
| 초 | 칠판 | 자막 |
|---|---|---|
| 0–3 | ① 같은 곡, 같은 시간 / A·B 1시간 | 같은 곡을, 같은 시간 동안 연습해도 |
| 3–6 | 결과 △ / ☆ | 결과는 사람마다 다릅니다. |
| 6–9.5 | ② 피아노 전공생 17명 + 건반 | 피아노 전공생 17명의 연습을 지켜본 연구가 있어요. |
| 9.5–12 | 오래 반복 ✕ | 잘 친 사람은, 오래 친 사람이 아니었습니다. |
| 12–15 | 악보 + 틀린 두 마디 동그라미 | 틀린 자리를 찾아, 그 자리를 고친 사람. |
| 15–18 | ③ 얼마나 오래 → 무엇을 고칠지 | 얼마나 오래보다, 무엇을 고칠지 보세요. |
| 18–22.5 | 진도보다 이해를 먼저 봅니다. | 에녹실용음악학원 시흥점 · 모든 과정 1:1 |

## 다시 만들기
```
python3 gen.py                      # video.html (브라우저에서 열면 재생 미리보기)
node record.mjs 30                  # video.mp4 (ffmpeg 필요, 경로는 FFMPEG 환경변수)
```
문구·타이밍은 gen.py의 `S`(칠판), `SUBS`(자막)에서 고친다.
