# 칠판 설명 영상 — 같은 연습, 다른 결과

- 진행: 에녹이 (`../디어에녹_01_무대떨림/mascot.py` 모양) — 자막이 나올 때 입을 여닫고, 지시봉으로 칠판에서 그려지는 자리를 가리킨다 (gen.py `POINT`)
- 규격: 1080×1920 (릴스), 14.5초, 30fps, 소리 없음 → 음악·내레이션은 캡컷에서 얹기
- 근거: Duke, Simmons & Cash (2009) — 피아노 전공생 17명의 연습 관찰. 잘 친 사람은 연습 시간이 아니라 틀린 곳을 바로 찾아 고치는 방식에서 달랐다.

## 장면·자막 (내레이션 대본으로 그대로 써도 됨)
| 초 | 칠판 | 자막 |
|---|---|---|
| 0–3 | ① A·B 같은 1시간 → 결과 △ / ☆ | 같은 시간 연습해도, 결과는 다릅니다. |
| 3–5.2 | ② 피아노 전공생 17명 + 건반 | 피아노 전공생 17명을 지켜본 연구에서 |
| 5.2–7.2 | 오래 반복 ✕ | 오래 친 사람보다 |
| 7.2–9.5 | 악보 + 틀린 두 마디 동그라미 | 틀린 곳을 고친 사람이 잘 쳤어요. |
| 9.5–12 | ③ 얼마나 오래 → 무엇을 고칠지 | 얼마나 오래보다, 무엇을 고칠지. |
| 12–14.5 | 진도보다 이해를 먼저 봅니다. | 에녹실용음악학원 시흥점 · 모든 과정 1:1 |

## 다시 만들기
```
python3 gen.py                      # video.html (브라우저에서 열면 재생 미리보기)
node record.mjs 30                  # video.mp4 (ffmpeg 필요, 경로는 FFMPEG 환경변수)
```
문구·타이밍은 gen.py의 `S`(칠판), `SUBS`(자막)에서 고친다.
