# 구성안: ENOCH ISSUE No.01 화성
- 분류: ENOCH ISSUE No.01
- 하이라이트: ENOCH
- 연결되는 ENOCH 원칙: 1 진도보다 이해를 먼저 봅니다 / 3 기본은 건너뛰지 않습니다
- 우리만 할 수 있는 이야기: ENOCH이 화성을 가르치는 순서 (듣기 → 이유 → 손). **초안이며 학원 확인 필요** — 실제 수업 순서와 다르면 5장을 고친다.
- 누구를 위한 글인가: 입시 · 취미 · 성인 (코드를 외워 왔지만 왜 그렇게 되는지 모르는 사람)
- 장수: 6장

| 장 | 역할 | 핵심 메시지 한 줄 | 레이아웃 | 사진 |
|---|---|---|---|---|
| 1 | 표지 | 화성 — 코드를 외우기 전에, 먼저 듣는 법 | cover (black) | 없음 |
| 2 | 정의 | 화성은 음이 겹쳐 만드는 색이다 | point | 없음 |
| 3 | 기본 | 코드는 머무름·움직임·당김, 세 역할로 읽는다 | chords | 없음 |
| 4 | 이유 | G7이 C로 가는 건 B·F의 부딪힘이 풀리기 때문 | point | 없음 |
| 5 | ENOCH | ENOCH은 이름보다 소리, 소리보다 이유를 먼저 가르친다 | list | 없음 |
| 6 | 마무리 | 진도보다 이해를 먼저 봅니다. | closing (black) | 없음 |

정보형(철학) 콘텐츠이므로 사진 없이 타이포그래피로 구성한다.

## 사실 확인
- C 메이저 기준
  - C = C E G (I, 토닉 — 안정)
  - F = F A C (IV, 서브도미넌트 — 토닉에서 벗어나는 움직임)
  - G7 = G B D F (V7, 도미넌트 — 토닉으로 당기는 긴장)
- G7의 B–F는 증4도(트라이톤). 해결 시 B → C (반음 위), F → E (반음 아래)
- 조성 음악의 화음은 토닉·서브도미넌트·도미넌트 세 기능으로 분류하는 것이 기능화성의 기본 설명이다.
- 출처: 기능화성 기초 (일반 화성학 교재 공통 내용), 구성음은 직접 계산

## 학원에 확인할 것
- 5장 "화성을 가르치는 순서(듣기 → 이유 → 손)"가 실제 수업과 맞는지, 실제 수업에서 쓰는 예시(곡, 연습 방법)가 있으면 받아서 반영
