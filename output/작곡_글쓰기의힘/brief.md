# 구성안: 작곡 — 곡은, 문장에서 시작돼요 (작곡과 글쓰기)

- 디자인: 이 편만 예외 — 블랙 바탕 + 라임 큰 제목 + 아이보리 둥근 카드 + 얇은 원 (원장님 참고 이미지 결, 2026-10-11 요청). 소스 `deck.html`.
- 핵심 메시지: 매일 읽고 쓰는 습관이 가사의 재료가 되고, 나만의 문장(세계관)이 곡을 나답게 만든다.
- 연결 원칙: 2. 같은 곡도, 사람마다 다르게 가르칩니다 / 시그니처 "나만의 진짜 소리를 찾는 곳."
- 우리만 할 수 있는 이야기: 작곡도 모든 과정 1:1.

| 장 | 메시지 |
|---|---|
| 1 | 곡은, 문장에서 시작돼요 (표지) |
| 2 | 멜로디만큼, 말이 필요해요 — 같은 코드, 다른 곡 |
| 3 | 읽는 만큼, 쓸 수 있는 말이 늘어나요 |
| 4 | 매일 쓰면, 내 말투가 생겨요 — 하루 세 줄 |
| 5 | 나의 세계관은 디테일로 드러나요 — 같은 그리움, 다른 문장 |
| 6 | 이번 주, 노트 한 권 — 읽고, 바꾸고, 소리 내기 |
| 7 | 나만의 진짜 소리는, 나만의 문장에서 + 원칙 2 + 주소 |
